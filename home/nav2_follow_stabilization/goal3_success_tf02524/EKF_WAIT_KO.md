# 성공본5cm의 EKF 지연 대기 전용 실행

로그 local_avoidance_trial_1794907942045140815.jsonl에서 마지막 EKF 시각1794908060825381618 이후 새 EKF가 관측되지 않아 약0.811초에 FILTERED_STALE로 종료됐다. 원시 오돔/IMU/모터 응답은 계속 도착했다. EKF 발행 또는 수신이 끊긴 내부 원인은 아직 특정하지 않았다.

원본 evaluation3_reference_wait는 그대로 보존했다. 별도 evaluation3_ekf_wait의 평가 실행기만 .6초 EKF 지연에서 조기에 속도0 대기로 진입한다. 정지 명령은 신선한 원시 오돔/IMU/스캔의 원본 시각으로만 지지하며, 오래된 EKF 값을 새 시각으로 바꾸거나 이동에 쓰지 않는다.

새 EKF/스캔 정렬, 새 시각3개 이상, 정지 피드백을 1초 안정 확인하면 같은 단계에서 재개한다. 장기 단절 시 시간 제한 없이 대기한다. 미래/잘못된 EKF, 원시/IMU/스캔 고장 및 실제 모터 오류는 그대로 거부한다.

원본의 정지5cm/여유10cm/경로/추종/오돔 계산/점프 검사/.3초 모터 감시는 바꾸지 않았다. runtime 차이는 평가 실행기1개와 입력 검사 helper1개뿐이다.

드라이버/센서/중계기는 유지. 양쪽 시작 위치에서 정지·후발 비무장 상태로 기존 capture_reference.bash로 새 기준선을 저장한 뒤 start_evaluation3_ekf_wait.bash를 실행한다. 새 실행기는 원본 capture가 저장한 최신 기준선 경로를 명시적으로 전달받는다. 물리 주행 성공 판정은 아직 하지 않았다.
